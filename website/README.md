# Joshiverse and SASI

Independent Next.js website for Joshiverse and the Share A Smile Initiative. Kept under `website/` while original Create React App remains untouched.

## Setup
Run `npm install`, `npm run typecheck`, `npm run build` from this directory.

## URLs
- `/`: Joshiverse
- `/sasi`: Share A Smile Initiative
- `/sasi/outreaches/ready-set-grow`: Kaduna 2026 outreach

`joshiverse.com` and `sasi.joshiverse.com` are planned hostnames; SASI hostname needs a tested rewrite to `/sasi` before DNS assignment. No DNS has been changed.
